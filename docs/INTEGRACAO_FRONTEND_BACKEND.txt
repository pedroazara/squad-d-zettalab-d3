9) COMO RODAR (PASSO A PASSO)

9.1) Rodar o backend (FastAPI)
1. No terminal, a partir da raiz do repositorio:
  cd api
2. Criar ambiente virtual (primeira vez):
  python -m venv .venv
3. Ativar ambiente virtual:
  Linux/macOS: source .venv/bin/activate
  Windows PowerShell: .venv\Scripts\Activate.ps1
4. Instalar dependencias:
  pip install -r requirements.txt
5. Subir API:
  uvicorn main:app --reload
6. Validar:
  API: http://127.0.0.1:8000
  Health: http://127.0.0.1:8000/health
  Swagger: http://127.0.0.1:8000/docs

9.2) Rodar o frontend (Vite)
1. Em outro terminal, entrar na pasta web:
  cd web
2. Instalar dependencias (primeira vez):
  npm install
3. Criar arquivo .env local (opcional, recomendado):
  copiar .env.example para .env
4. Subir frontend:
  npm start
5. Acessar:
  http://127.0.0.1:4173
